C#の void って何？

まず結論

void は、

「このメソッド*1は値を返しません」

という意味。

正しい理解

void → 戻り値*2 がない

実際に見てみる

void Attack()
{
    Console.WriteLine("攻撃！");
}

このメソッドには、 ちゃんと処理が入っている。 

Console.WriteLine("攻撃！");

この場合は、 「攻撃！と表示する」という処理をしたあと、 何も値を返さない という意味。

じゃあ「値を返す」って何？

例えばこんなメソッド。 

int Add(int a, int b)
{
    return a + b;
}

これは、 a と b を足した結果を返している。 

int result = Add(3, 5);

とすると、 

result = 8;

となる。

つまり int は、 「このメソッドは int 型の値を返します」 という意味。

void と int を比べてみる

値を返すメソッド 

int Add(int a, int b)
{
    return a + b;
}
Add(3, 5) を実行すると、 8という値が返ってくる。

値を返さないメソッド 

void Attack()
{
    Console.WriteLine("攻撃！");
}
Attack() を実行すると、 処理は行われるが、値は返ってこない。

じゃあ () は何？

正確には、 メソッドが受け取る引数*3を書く場所 

void Attack()
{
    Console.WriteLine("攻撃！");
}

この場合は何も受け取らないので、 () の中が空になっている。

例えば敵にダメージを与えるメソッドなら、 

void Attack(int damage)
{
    Console.WriteLine(damage + "ダメージ！");
}

となる。

この場合、 int damage が 「受け取るデータ」 。 

Attack(100);

とすれば、 damage に 100 が渡される。

メソッドを「入力 → 処理 → 出力」で考える

メソッドを理解するときは、 入力 → 処理 → 出力 と考えるとかなり分かりやすい。 

int Add(int a, int b)
{
    return a + b;
}

これを図にすると、

入力：3、5
↓
処理：3 + 5
↓
出力：8

という感じ。

一方、 

void Attack(int damage)
{
    Console.WriteLine(damage + "ダメージ！");
}

なら、

入力：100
↓
処理：「100ダメージ！」と表示
↓
出力：なし

メソッド宣言を分解すると

void Attack(int damage)
{
    Console.WriteLine(damage + "ダメージ！");
}

それぞれの部分には、 ちゃんと意味がある。

void
↓
戻り値の型
「値を返しません」
Attack
↓
メソッド名
(int damage)
↓
引数のリスト
「int型のdamageを受け取ります」
{ ... }
↓
メソッド本体
「実際に何をするか」

まとめ

void は、 「このメソッドは値を返さない」 という意味。

() は 「関数の入口」ではなく、 引数を書く場所。

なので、 

void Attack(int damage)
{
    Console.WriteLine(damage + "ダメージ！");
}

は、

「Attackという名前のメソッドを作る。
int型のdamageを受け取り、
何らかの処理をする。
ただし、処理結果として値は返さない。」
*1 メソッド（method）
C#で「処理をまとめたもの」のこと。 他のプログラミング言語では 「関数（function）」と呼ばれるものに近い。 ↑ 本文へ
*2 戻り値（return value）
メソッドを呼び出した側に返される値のこと。 return を使って返す。

例えば、 return 8; なら、 「8という値を呼び出した側に返す」 という意味。 ↑ 本文へ
*3 引数（argument）
メソッドを呼び出すときに、 メソッドへ渡すデータのこと。

例えば、 Attack(100); なら、 100 が引数。

なお、 int damage のように 「受け取るデータを宣言したもの」は 正確には「仮引数（parameter）」と呼ぶ。 初心者のうちは、 「メソッドに渡すデータ」 と考えておけばOK。 ↑ 本文へ

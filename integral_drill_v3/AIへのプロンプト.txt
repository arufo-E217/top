# 積分演習 問題ファイル仕様書

このドキュメントは、「積分演習」サイトで使用する問題ファイルの作成規則を定義するものです。

Geminiなどの生成AIに問題を作成させる場合も、**この仕様を厳密に守ってください。**

---

# 1. 基本構造

問題ファイルはUTF-8で保存されたテキストファイルです。

1つのファイルに1問だけ書くことも、複数問を連続して書くこともできます。

1問は必ず、

```text
=== 問題 ===
```

から始まり、

```text
=== 問題終了 ===
```

で終了します。

基本形は以下です。

```text
=== 問題 ===
問題名: ...
制限時間: ...

問題:
...

ダミー:
- ...
- ...
- ...
- ...

答え:
...

解説:
...

=== 問題終了 ===
```

複数の問題を書く場合は、次のように続けます。

```text
=== 問題 ===
問題名: ...
制限時間: ...

問題:
...

ダミー:
- ...
- ...
- ...
- ...

答え:
...

解説:
...

=== 問題終了 ===

=== 問題 ===
問題名: ...
制限時間: ...

問題:
...

ダミー:
- ...
- ...
- ...
- ...

答え:
...

解説:
...

=== 問題終了 ===
```

---

# 2. 各セクションの一覧

問題には以下のセクションがあります。

| セクション   | 必須 | 内容      | 記述形式         |
| ------- | -- | ------- | ------------ |
| `問題名:`  | 任意 | 問題のタイトル | プレーンテキスト     |
| `制限時間:` | 必須 | 制限時間    | 秒数           |
| `問題:`   | 必須 | 実際の問題文  | HTML + LaTeX |
| `ダミー:`  | 必須 | 誤答選択肢   | LaTeX        |
| `答え:`   | 必須 | 正解選択肢   | LaTeX        |
| `解説:`   | 任意 | 解答・解説   | HTML + LaTeX |

重要なのは、**各セクションで使用できる記法が違う**ことです。

---

# 3. `問題名:` セクション

## 目的

問題一覧に表示する問題のタイトルです。

必須ではありません。

```text
問題名: 部分積分の基本
```

のように記述します。

問題名を設定しない場合は、

```text
問題名:
```

として空欄にできます。

## 使用可能な記法

基本的にプレーンテキストのみを使用してください。

LaTeXは使用しないでください。

### 良い例

```text
問題名: 部分積分の基本
```

```text
問題名: 三角関数を含む定積分
```

### 避ける例

```text
問題名: \int x e^x dx
```

問題名では数式を使用せず、簡潔なタイトルにしてください。

---

# 4. `制限時間:` セクション

問題を解き始めてからの制限時間を指定します。

単位は**秒**です。

```text
制限時間: 60
```

これは60秒を意味します。

## 例

30秒:

```text
制限時間: 30
```

1分:

```text
制限時間: 60
```

3分:

```text
制限時間: 180
```

10分:

```text
制限時間: 600
```

## 時間制限なし

時間制限を設定しない場合は、

```text
制限時間: 0
```

としてください。

---

# 5. `問題:` セクション

ここが実際にユーザーへ表示される問題本文です。

このセクションでは、

* HTML
* LaTeX
* 画像

を使用できます。

---

# 6. 問題文の通常テキスト

通常の文章はHTMLの`<p>`タグを使用してください。

```html
<p>次の不定積分を求めよ。</p>
```

複数の段落を書く場合は、

```html
<p>次の不定積分を求めよ。</p>

<p>ただし、積分定数を \(C\) とする。</p>
```

のようにします。

---

# 7. 問題文中のLaTeX

数式には必ずLaTeXを使用してください。

このサイトでは、HTML中に以下の形式でLaTeXを記述します。

## 独立した数式

```html
<div data-math="block">
\int x^2\,dx
</div>
```

これは画面上で大きな独立した数式として表示されます。

## 文章中の数式

文章中の数式も独立した`div`にしなければ正しくLaTeXが表示されません。
必ず文章中でも独立したdivにしてください。

例えば、

```html
<p>次の積分を求めよ。</p>

<div data-math="block">
\int_0^1 x^2\,dx
</div>
```

としてください。

---

# 8. LaTeXの重要ルール

## 必ずLaTeXとして記述する

例えば、

```text
x^2
```

はLaTeXとして正しいです。

しかし、

```text
x²
```

のようなUnicode数学記号は、問題ファイルではなるべく使用しないでください。

---

## 分数

分数は必ず、

```latex
\frac{1}{2}
```

としてください。

以下は使用しないでください。

```text
1/2
```

特に数学的な選択肢では、

```latex
\frac{x+1}{x-1}
```

のように書いてください。

---

# 9. 指数

指数は`^`を使用します。

```latex
x^2
```

複数文字の場合は`{}`で囲みます。

```latex
x^{10}
```

```latex
e^{x+1}
```

### 悪い例

```latex
x^10
```

これはLaTeXとしても意味は通りますが、複雑な式では必ず、

```latex
x^{10}
```

としてください。

---

# 10. 添字

添字も`{}`を使用してください。

```latex
x_1
```

```latex
x_{10}
```

```latex
a_{n+1}
```

---

# 11. 積分

積分記号には必ず`\int`を使用してください。

```latex
\int x^2\,dx
```

定積分の場合、

```latex
\int_0^1 x^2\,dx
```

とします。

上下限が複数文字の場合は`{}`を使用します。

```latex
\int_{0}^{a} x^2\,dx
```

---

# 12. 微分記号

`dx`などの微分記号の前には、可能な限り`\ `または`\,`を入れてください。

推奨:

```latex
\int x^2\,dx
```

避ける:

```latex
\int x^2dx
```

---

# 13. 括弧

複雑な式では括弧を明示してください。

```latex
(x+1)^2
```

```latex
\left(x+1\right)^2
```

特に分数の中では、

```latex
\frac{1}{x+1}
```

のように記述します。

---

# 14. 三角関数

三角関数はLaTeXのコマンドを使用してください。

正しい:

```latex
\sin x
```

```latex
\cos x
```

```latex
\tan x
```

引数が複雑な場合:

```latex
\sin(x+1)
```

```latex
\cos(2x)
```

---

# 15. 対数

自然対数は、

```latex
\log x
```

とします。

絶対値を含む場合、

```latex
\log|x|
```

とします。

例えば、

```latex
\int \frac{1}{x}\,dx
```

の答えは、

```latex
\log|x|+C
```

です。

---

# 16. 絶対値

絶対値は、

```latex
|x|
```

または、

```latex
\left|x\right|
```

を使用してください。

複雑な式の場合は、

```latex
\left|x^2-1\right|
```

を推奨します。

---

# 17. 数式をHTMLとして直接書かない

以下のような記述は避けてください。

```html
<div>
∫ x² dx
</div>
```

必ず、

```html
<div data-math="block">
\int x^2\,dx
</div>
```

としてください。

---

# 18. 画像

問題文には画像を使用できます。

例えば、

```html
<p>次の図を参考にして答えよ。</p>

<img src="figure01.png" alt="問題の図">
```

とします。

画像ファイルは問題ファイルと同じディレクトリに置くことを推奨します。

例えば、

```text
problems.txt
figure01.png
figure02.png
```

という構成です。

サブフォルダを使用する場合は、

```html
<img src="images/figure01.png" alt="問題の図">
```

とします。

---

# 19. `ダミー:` セクション

ここには**誤答の選択肢**を書きます。

選択肢はLaTeXで記述してください。

1行につき1つの選択肢を書きます。

例えば、

```text
ダミー:
- x^2+C
- 2x^2+C
- \frac{1}{2}x^2+C
- x^2
```

とします。

`-` は選択肢を区切るための記号です。

---

# 20. ダミー選択肢の重要ルール

**正答と数学的に同値な選択肢を絶対に作らないでください。**

例えば正答が、

```latex
e^2+C
```

の場合、

```latex
\frac{1}{1}e^2+C
```

は数学的に同じなので、ダミーとして使用してはいけません。

同様に、

```latex
2x
```

と

```latex
x+x
```

も同じ値なので避けてください。

---

# 21. ダミー選択肢の作り方

ダミーは単なるランダムな式ではなく、

**「どこかの計算を間違えた場合に出てきそうな答え」**

にしてください。

例えば、

```latex
\int x^2\,dx
```

の正答が、

```latex
\frac{1}{3}x^3+C
```

なら、

```text
ダミー:
- x^3+C
- \frac{1}{2}x^2+C
- 2x^3+C
- \frac{1}{3}x^2+C
```

のようにします。

---

# 22. `答え:` セクション

ここには正解となる選択肢を**1つだけ**書きます。

例えば、

```text
答え:
\frac{1}{3}x^3+C
```

です。

`答え:` に書いたLaTeXは、そのまま正解選択肢として使用されます。

---

# 23. 答えとダミーの表記統一

数学的に同じ式であっても、表記が違うものを複数の選択肢にしないでください。

例えば、

```latex
e^2+C
```

と

```latex
1e^2+C
```

は同じです。

また、

```latex
\frac{2}{4}
```

と

```latex
\frac{1}{2}
```

も同じです。

さらに、

```latex
x+x
```

と

```latex
2x
```

も同じです。

**選択肢は必ず数学的に異なるものにしてください。**

---

# 24. `解説:` セクション

解説は任意です。

空欄でも構いません。

```text
解説:
```

だけでも問題として成立します。

解説ではHTMLとLaTeXを使用できます。

例えば、

```text
解説:
<p>まず、各項をそれぞれ積分する。</p>

<div data-math="block">
\int x^2\,dx=\frac{x^3}{3}
</div>

<p>したがって答えは次のようになる。</p>

<div data-math="block">
\frac{x^3}{3}+C
</div>
```

---

# 25. 解説でのHTML

解説では以下のようなHTMLを使用できます。

```html
<p>文章</p>
```

```html
<br>
```

```html
<strong>重要</strong>
```

```html
<ul>
<li>ポイント1</li>
<li>ポイント2</li>
</ul>
```

ただし、複雑なHTMLは避けてください。

---

# 26. 解説での数式

数式は問題本文と同じ形式です。

```html
<div data-math="block">
\int x^2\,dx=\frac{x^3}{3}+C
</div>
```

---

# 27. 完全な問題例

以下は正しい問題ファイルの例です。

```text
=== 問題 ===
問題名: 部分積分
制限時間: 180

問題:
<p>次の不定積分を求めよ。</p>

<div data-math="block">
\int xe^x\,dx
</div>

ダミー:
- xe^x+C
- e^x+C
- xe^x+e^x+C
- x^2e^x+C

答え:
xe^x-e^x+C

解説:
<p>部分積分を用いる。</p>

<div data-math="block">
\int u\,dv=uv-\int v\,du
</div>

<p>ここで</p>

<div data-math="block">
u=x,\qquad dv=e^x\,dx
</div>

<p>とすると、</p>

<div data-math="block">
du=dx,\qquad v=e^x
</div>

<p>したがって、</p>

<div data-math="block">
\int xe^x\,dx
=xe^x-\int e^x\,dx
=xe^x-e^x+C
</div>

=== 問題終了 ===
```

# 28. AIに問題を生成させる場合の重要事項

Geminiなどの生成AIに問題を作らせる場合は、以下を厳守してください。

1. 問題ファイル仕様を変更しない。
2. セクション名を変更しない。
3. `=== 問題 ===` と `=== 問題終了 ===` を必ず使用する。
4. `問題:` の内容はHTML + LaTeXで記述する。
5. `ダミー:` はLaTeXのみで記述する。
6. `答え:` はLaTeXのみで記述する。
7. `解説:` はHTML + LaTeXで記述する。
8. LaTeXの数式をUnicode数学記号に変換しない。
9. `\frac`、`\int`、`\sin`、`\cos`、`\log`などのLaTeXコマンドをそのまま使用する。
10. `\` を削除しない。
11. 数式の中で不要なHTMLを使用しない。
12. 正答と数学的に同値なダミーを作らない。
13. ダミーは計算ミスとして自然なものにする。
14. `答え:` には正答を1つだけ書く。
15. 問題ごとに必ず独立した`=== 問題 ===`～`=== 問題終了 ===`を使用する。

# 29. AIへの推奨プロンプト

問題を生成するAIには、次のように指示することを推奨します。

```text
以下の「積分演習 問題ファイル仕様書」に完全に従って問題を生成してください。

重要:
- 出力は問題ファイルの内容だけにしてください。
- Markdownのコードブロックで囲まないでください。
- 解説や前置きは不要です。
- 指定されたセクション名を変更しないでください。
- LaTeXは必ずLaTeXとして記述してください。
- Unicodeの数学記号に変換しないでください。
- 問題本文と解説ではHTMLとLaTeXを使用してください。
- ダミーと答えはLaTeXのみで記述してください。
- 正答と数学的に同値なダミーを絶対に作らないでください。
- 各問題は必ず「=== 問題 ===」で開始し、「=== 問題終了 ===」で終了してください。

[ここに問題ファイル仕様書を貼り付ける]

生成条件:
- 高校数学の範囲
- 積分法
- 難易度: ○○
- 問題数: ○問
- 制限時間: ○秒
```

# 30. AI生成時の最終チェック

生成されたファイルは、サイトに読み込ませる前に以下を確認してください。

### 構造

```text
=== 問題 ===
↓
問題名:
↓
制限時間:
↓
問題:
↓
ダミー:
↓
答え:
↓
解説:
↓
=== 問題終了 ===
```

### 数式

* `\frac{}` を使用している
* `^` の複数文字指数を `{}` で囲んでいる
* `\int` を使用している
* `\,dx` を使用している
* `\sin`、`\cos`、`\log`などを正しく使用している
* バックスラッシュ `\` が消えていない

### 選択肢

* 正答が1つだけ存在する
* 正答と数学的に同値なダミーが存在しない
* ダミーが実際に起こりうる計算ミスになっている

# 31. 推奨されるファイル構成

問題と画像をまとめて管理する場合は、次の構成を推奨します。

```text
problems/
├── basic.txt
├── substitution.txt
├── integration_by_parts.txt
├── definite_integral.txt
└── images/
    ├── problem001.png
    ├── problem002.png
    └── problem003.png
```

例えば`basic.txt`には基本問題だけ、

`substitution.txt`には置換積分だけ、

というように分けると管理しやすくなります。

---

# 32. 最重要ルール

この問題ファイルでは、

**「問題文・解説」と「選択肢・答え」で使用する記法が異なります。**

### 問題・解説

```text
HTML + LaTeX
```

### ダミー・答え

```text
LaTeXのみ
```

したがって、

```text
ダミー:
- <div data-math="block">x^2</div>
```

とは書かず、

```text
ダミー:
- x^2
```

としてください。

また、

```text
問題:
x^2
```

とするのではなく、

```text
問題:
<div data-math="block">
x^2
</div>
```

としてください。

この区別を守ることで、問題ファイルの構造が安定し、生成AIから問題を大量に生成する場合でも扱いやすくなります。

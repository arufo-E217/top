# 積分演習 v3

## 問題ファイル

問題データは `problems.txt` に記述します。

1問の範囲は、

=== 問題 ===

から

=== 問題終了 ===

までです。

複数の問題を同じファイルに連続して記述できます。

## テンプレート

```text
=== 問題 ===
問題名: 基本的な不定積分
制限時間: 60
問題:
<p>次の不定積分を求めよ。</p>
<div data-math="block">\int (3x^2+4x-5)\,dx</div>

ダミー:
- x^3+2x^2-5x+C
- 3x^3+2x^2-5x+C
- x^3+4x^2-5x+C
- x^3+2x^2-5x

答え:
x^3+2x^2-5x+C

解説:
各項をそれぞれ積分する。
=== 問題終了 ===
```

## 制限時間

`制限時間:` は秒単位です。

```text
制限時間: 60
```

なら60秒。

```text
制限時間: 300
```

なら5分。

```text
制限時間: 0
```

なら時間制限なしです。

問題ごとに違う制限時間を設定できます。

## 解答時間

問題を開いた瞬間から計測開始します。

「解答を確定」を押した時点までの時間を、

```text
解答までの時間：01:23.4
```

のように表示します。

1000分の1秒単位を内部では計測し、表示は0.1秒単位です。

## 時間切れ

ホーム画面の

「時間制限到達時の動作」

から選択できます。

### 正答を表示して終了する

時間切れになった瞬間に解答を終了し、正答を表示します。

この場合、解答していないので正答数には加算されません。

### そのまま解答を続ける

時間切れ後も解答できます。

制限時間を超えた後も実際の解答時間は継続して計測されます。

例えば制限60秒で75.4秒後に答えた場合、

```text
解答までの時間：01:15.4
```

と表示されます。

## 問題本文

問題本文はHTMLを使用できます。

画像も、

```html
<img src="figure.png">
```

のように配置できます。

LaTeXを表示する場合は、

```html
<div data-math="block">
\int_0^1 x^2\,dx
</div>
```

のように書きます。

## 注意

選択肢の数学的同値性はサイト側では判定しません。

例えば、

```text
e^2+C
```

と

```text
(1/1)e^2+C
```

を両方書けば、別の選択肢として扱われます。

問題作者側で、明らかに同値な選択肢を避けてください。

## ファイルの再読み込み

「問題ファイルを開く」で選んだファイルはブラウザに保存されます。

次回は「保存したファイルを再読込」で同じファイルを読み込めます。

Chrome / Edge の最新版を推奨します。

# 高性能・高精度 Web 電卓

## ファイル
- `index.html` : 画面構造
- `style.css` : デザイン・スマートフォン操作対策
- `script.js` : 計算エンジン・入力処理

## 特徴

### 1. `=` 連打
例えば、

`2 + 3 =` → `5`

そのまま `=` → `8`

さらに `=` → `11`

のように、直前と同じ演算を繰り返します。

### 2. BigIntによる高精度計算
JavaScriptの通常の `Number` は整数を約15～16桁程度しか正確に扱えません。
この電卓では、内部の整数部分を `BigInt` で保持するため、非常に大きな整数でも精度を保てます。

小数も「整数 + 小数桁数」の形で保持します。

例:
- `123456789012345678901234567890 + 1`
- `999999999999999999999999999999 × 999999999999999999`

などを通常の `Number` より正確に扱えます。

### 3. 除算
割り切れない除算は、小数点以下100桁まで計算し、最後の桁で四捨五入します。

`1 ÷ 3`
→ `0.333333333333...`（最大100桁）

### 4. 指数表記を使わない
`1.6854e+10` のような指数表記にはせず、通常の10進表記で表示します。

例:
`16854000000`

### 5. スマートフォン対策
以下を組み込んでいます。

- `touch-action: manipulation`
- viewportの拡大禁止
- `user-scalable=no`
- `-webkit-user-select: none`
- ダブルタップズーム対策
- タッチ時のボタン状態表示
- Pointer Events
- iOS Safariのgestureイベント抑制
- `preventDefault()` によるキーボード操作との競合防止

通常の `touchstart` と `click` を二重に処理する実装を避けているため、
「1回タップしたのに2回入力される」問題も起こしにくい構成です。

## 制限
- 1つの数値に入力できる桁数は5000桁です。
- 除算結果は小数点以下100桁までです。
- `%` は「現在値 ÷ 100」という一般的な単純パーセントとして実装しています。
- 数式の括弧入力や関数電卓機能はまだありません。

## 起動
`index.html` をブラウザで開くだけで動作します。
外部ライブラリは使用していません。
